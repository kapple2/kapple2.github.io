자바스크립트 KBASIC 인터프리터(원작: Joshua Bell 의 Applesoft BASIC Interpreter in JavaScript)를 위한 빠른 참고서입니다. 키워드마다 한글 키워드(영어 애플소프트 키워드)를 함께 적었습니다. 영어 키워드도 그대로 쓸 수 있고 둘을 섞어 써도 됩니다.

이 판은 애플 II Plus 의 애플소프트를 따릅니다(이 판에 대하여).

한글 키워드의 규칙:

  • 한글이 이어진 곳에서는 가장 긴 키워드를 먼저 잡습니다. 출력이름$ 는 출력 + 변수 이름$ 입니다.
  • 영어 토큰 끝의 = : # 는 치지 않습니다(색상 5, 상한 36863, 보내기 1). ( 로 끝나는 토큰(탭이동 빈칸 스크린)은 ( 까지 칩니다.
  • 주석은 # (영어 REM 도 됩니다), 입력용 별칭이 둘 있습니다: 까지 (= 부터 (TO)), 조건 (= 분기 (ON)).
  • 변수 이름에 한글을 쓸 수 있습니다.

식의 BNF 문법

더 깊이 파고드는 분들을 위해...

    Expression               := OrExpression
    OrExpression             := AndExpression [ 'OR' AndExpression ... ]
    AndExpression            := RelationalExpression [ 'AND' RelationalExpression ... ]
    RelationalExpression     := AdditiveExpression [ ( '=' | '<' | '>' | '<=' | '=<' | '>=' | '=>' | '<>' | '><' ) AdditiveExpression ... ]
    AdditiveExpression       := MultiplicativeExpression [ ( '+' | '-' ) MultiplicativeExpression ... ]
    MultiplicativeExpression := PowerExpression [ ( '*' | '/' ) PowerExpression ... ]
    PowerExpression          := UnaryExpression [ '^' UnaryExpression ]
    UnaryExpression          := ( '+' | '-' | 'NOT' ) UnaryExpression
                              | FinalExpression
    FinalExpression          := number-literal
                              | string-literal
                              | 'FN' user_function_name '(' Expression ')'
                              | function_name '(' Expression [, Expression ...] ')'
                              | identifier [ '(' Expression [, Expression ...] ')' ]
                              | '(' Expression ')'

(문법은 영어 키워드로 적었습니다. 한글 키워드는 읽기 전에 같은 영어 키워드로 바뀝니다.)

예제 파일 몇 개는 서버 쪽 저장소에 있다가 필요할 때 클라이언트 쪽 가상 파일 시스템(VFS)으로 읽힙니다. 이 판에는 그 저장소(vfs/)가 없으므로 파일은 프로그램이 직접 만들어 써야 합니다. 파일을 만들거나 쓰면 VFS 에 쓰이고, 이어서 읽으면 VFS 에서 읽습니다. 파일은 페이지를 다시 읽으면 사라집니다.
